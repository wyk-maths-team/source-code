PyBot

A chatbot written entirely in Python rules by 1,000+ agents — no model, no weights. Each turn is independent: it does not remember the previous one.

Every message takes 20–40 seconds. It is not slow because it is thinking — it is slow because 528 modules each get a turn at matching your text.
Ask it something. Try what is 17 times 23 or is 1000003 a prime number.
