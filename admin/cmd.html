Server Terminal Guide

Execute arbitrary JavaScript code in the Node.js environment (Vercel serverless).
You have access to the full Node.js runtime with the following globals:

  • require – load any Node module (e.g., require('fs'), require('os'))
  • console – output will be captured and displayed
  • process – access environment variables, cwd, etc.
  • Buffer, setTimeout, Promise, etc.
  • db – the MongoDB database connection (same as in MongoDB mode, but you can also use it here)

Examples:

// View environment variables
Object.keys(process.env).filter(k => k.includes('MONGODB')).forEach(k => console.log(k, process.env[k]));

// List all collections
(await db.listCollections().toArray()).map(c => c.name);

// Use async/await
const fs = require('fs');
const files = await fs.promises.readdir('/tmp');
console.log(files);

Note: The code runs in a sandbox; require is allowed, but file system writes may be limited in serverless environment.
The result of the last expression is printed (if not undefined).
For security, only root users can access this terminal.

MongoDB Terminal Guide

Execute JavaScript code against the MongoDB database.
The code runs in a Node.js context with the following injected objects:

  • db – the MongoDB database instance (connected)
  • ObjectId – the MongoDB ObjectId constructor
  • console – output capture
  • ISODate – alias for Date (but you can use new Date())

Important: All operations are asynchronous. Use await or .then().

Common queries:

// Find all documents in a collection
await db.collection('users').find({}).toArray();

// Find with filter and projection
await db.collection('problems').find({ public: true }, { projection: { ans: 0 } }).toArray();

// Aggregation pipeline
await db.collection('submissions').aggregate([
  { $match: { correct: true } },
  { $group: { _id: '$problemId', count: { $sum: 1 } } }
]).toArray();

// Update documents
await db.collection('users').updateOne(
  { username: 'admin' },
  { $set: { banned: false } }
);

// Use ObjectId
const { ObjectId } = require('mongodb'); // already injected
await db.collection('discussions').findOne({ _id: new ObjectId('...') });

Note: Write operations (insert, update, delete) are allowed but use with caution.
The result of the last expression is printed (if not undefined).
Only root users can access this terminal.
