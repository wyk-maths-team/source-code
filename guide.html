User Guide

1. Platform Overview

  • The system is deployed on the Vercel serverless platform.
  • Data persistence is handled by MongoDB, with image assets stored via Cloudinary.

2. Submission Modes & Behaviour

  • Text Mode (numeric): The submitted answer is compared with the standard answer. A tolerance of \(10^{-6}\) is allowed for floating-point rounding.
  • Text Mode (advanced): For selected problems, the answer is evaluated by a custom logic function defined in the problem statement.
  • Photo Mode: This mode is supported but is not recommended for regular use, as marking requires manual review and may result in a longer feedback delay.
  • Discussions are automatically unlocked once a problem has been successfully solved.
  • During peak usage hours, operations involving database queries—such as submissions, favourites, and page loads—may experience slower response times due to server load.

3. Important Notes

  • A mandatory cooldown period of 5 seconds applies to each submission to prevent accidental duplicate requests.
  • Problem IDs may change over time. Some problems may be removed or hidden from the public list without prior notice.
  • Due to occasional technical anomalies in the OCR processing pipeline, certain problems may contain formatting errors, incomplete statements, or unclear descriptions. If you encounter any such issues, please use the Report button on the problem page.

4. Contest Rules

  • Contests are created by teachers and consist of a curated set of problems.
  • Enrolment is only permitted before the contest starts; once the contest has begun, no further participants may join.
  • For numeric-type problems, each incorrect submission incurs a penalty of 10 marks per problem.
  • In the event of a tie in total score, the ranking will be determined by the timestamp of the last submission—earlier submissions rank higher.

5. Additional Information

  • The platform includes several non-obvious features intended for advanced users.
  • The website is fully responsive and optimised for mobile devices.
  • All PDF resources provided on this site are either contributed by Mr Patrick Chung or sourced from publicly available materials, used with permission where applicable.
  • The judging engine and core logic are original developments, while the user interface design draws inspiration from established online judge systems.
