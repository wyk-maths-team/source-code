    A statement containing \dfrac (or any tall fraction) overflowed the
    statement pane. .katex-display carries overflow-x: auto, so the formula

    数学 stayed unreadable at the exact moment it got complicated.

    correctly (unlike transform, which would need height compensation).

    - There is a floor at 45%. Past that the text is unreadable, so the
    original horizontal scroll returns as the fallback for genuinely huge
    formulas.

    scale would freeze.

    tick() called refresh() whenever left <= 0. Since room.endAt stays in the

2026-10-24 16:26  feat(pk): staked PK mode (3 problems / 30 min / prize split)
    New api/pk-bet.js implements the betting format alongside the old room one.
    Flow
    - invite: stake >= 10000, deducted immediately from the sender (daily
    first, then global) and held in the pool. Refunded on decline/expire via
    refundInvite(), which claims status first so it cannot double-refund.
    - accept: acceptor must cover the same stake; 20% fee is taken from the
    pool; three public problems are picked near the difficulty implied by the
    pair's average rating; both players see them for 30 minutes.
    - submit: the server judges the answer (numeric, 1e-6) and stores one row
    per (player, problem); resubmitting overwrites, so only the last attempt
    per problem counts.
    - room/settle/result: settlement is idempotent (claims status first),
    writes a permanent pk_bet_results row, and room redirects to it.
    Scoring: per problem (1800 - T) * 100, T = seconds since start (1..1800).
    Total = sum of three. Higher total wins.
    Settlement: prize = pool * 0.8.
    weaker  = prize * ratioWeaker * F
    stronger = prize - that
    F is a token-balance subsidy (1 .. 1.25), capped at 0.99/ratioWeaker so the
    stronger side is never negative. Verified over 20000 random cases: never
    negative, always sums to prize.
    Pages: pk-bet-room.html (timer, 3 tabs, submit) and pk-bet-result.html
    (permanent, shows per-problem attempts, F, both payouts). The user-page
    Invite button prompts for a stake; pk-notify now polls the new endpoints
    and shows the stake in its card.

2026-10-18 19:22  fix: 修复 escapeHtml 返回函数对象导致源码泄漏到页面（线上 bug）
    现象：
    页面上出现 <img src="function esc(s) {...}">，函数源码被当成属性值渲染。
    根因：
    M4-1b 的转义迁移用错了写法：
    function esc(s) { return (window.DSHUI && DSHUI.esc) || function (s) {...}); }
    这里的 return 返回的是「函数本身」，没有 (s) 调用。
    于是模板字符串 `${escapeHtml(x)}` 会把函数 toString() 成源码插进 HTML。
    修复：
    改为
    function esc(s) { return ((window.DSHUI && DSHUI.esc) || function (s) {...})(s); }
    33 个文件 / 33 处全部修正（都在抽离后的 assets/js/pages/ 下）。
    tools/migrate-escape.mjs 的 FALLBACK 同步改正，并在注释里写清楚
